# 📊 Trading Wizard – מערכת לניתוח שווקים מבוססת AI

**Trading Wizard** הוא כלי מתקדם לניתוח טכני של שווקים פיננסיים, כולל **קריפטו, מניות, פורקס, חוזים עתידיים ועוד**.\
המערכת מאפשרת **העלאת גרפים, קבלת ניתוחים חכמים**, וניהול היסטוריית ניתוחים – הכול **בממשק מודרני ונוח**.

## ✨ תכונות עיקריות:

- **📊 העלאת גרפים לניתוח** – קבלת תובנות בזמן אמת.
- **🔍 אינדיקטורים חכמים** – רמות תמיכה, מגמות, סטופ לוס ועוד.
- **📁 ניהול היסטוריית ניתוחים** – מעקב אחר כל הניתוחים הקודמים שלך.
- **🔐 מערכת הרשאות** – רק משתמשים רשומים יכולים לגשת לדשבורד.
- **📡 אימות משתמשים** – הרשמה והתחברות באמצעות Supabase (כולל Google Auth).
- **💳 מודל מנויים דינמי** – ניהול תוכניות (Basic, Premium, Expert).

## 🚀 טכנולוגיות בשימוש:

- **Frontend:** Next.js, React, Tailwind CSS
- **Backend & DB:** Supabase (PostgreSQL), Stripe (בעתיד)
- **Authentication:** Supabase Auth (כולל Google Login)
- **Deployment:** Vercel

## 📦 התקנה והרצה

1. **שכפול הריפו**

```bash
git clone https://github.com/your-username/trading-wizard.git
cd trading-wizard
```

2. **התקנת חבילות**

```bash
npm install
```

3. \*\*הגדרת קובץ \*\***`.env.local`** (יש להוסיף את המפתחות מסופאבייס)

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
```

4. **הרצת הסביבה המקומית**

```bash
npm run dev
```
